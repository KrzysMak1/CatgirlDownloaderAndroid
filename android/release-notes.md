**Catgirl Downloader for Android 1.2.0** (Android 12+). Installs over 1.x.

### New
- **Custom background** (Preferences → Appearance): pick any image from your gallery to show behind
  the pictures, and set how much it is darkened (0–90%). The image is copied into the app, so it keeps
  working if you move or delete the original.

### Improved
- Rounded corners stay rounded while zooming, both on the image and on the edges of the viewing area.
- Build and release workflows use the latest GitHub Actions (Node 24).

**Catgirl Downloader na Androida 1.2.0** (Android 12+). Instaluje się na wersję 1.x.

### Nowości
- **Własne tło** (Ustawienia → Wygląd): wybierz dowolny obraz z galerii, który będzie widoczny za
  obrazkami, i ustaw, jak bardzo ma być przyciemniony (0–90%). Obraz jest kopiowany do aplikacji, więc
  działa nawet po przeniesieniu lub usunięciu oryginału.

### Ulepszenia
- Zaokrąglone rogi zostają zaokrąglone podczas powiększania, zarówno na obrazie, jak i na krawędziach
  obszaru podglądu.
- Workflowy budowania i wydań używają najnowszych wersji GitHub Actions (Node 24).

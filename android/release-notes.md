First stable release of **Catgirl Downloader for Android** (Android 12+), a port of the
[Nyarch Linux desktop app](https://github.com/NyarchLinux/CatgirlDownloader).

**Install:** download `CatgirlDownloader-*.apk` below and open it on your phone
(allow installing apps from your browser or file manager when asked).

> **Upgrading from a 0.5.x pre-release?** Uninstall it once first. Pre-releases were signed with a
> temporary key; from this version on, all updates are signed with the same key and install over
> the previous version.

### Features
- Sources: Catgirl (nekos.moe), Waifu, Danbooru (custom tags) and Kitsune (nekos.best)
- NSFW filter, auto reload, "About art" with artist and source link
- Fast loading: the next image is preloaded and pre-decoded in the background
- Optional original quality for Danbooru
- Save to `Pictures/CatgirlDownloader`, a folder of your choice, or "Save as"
- Pinch/double-tap zoom, animated GIF/WebP, Material You colors, English and Polish
